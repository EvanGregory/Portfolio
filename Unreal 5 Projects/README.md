# Unreal 5 Projects

These are two projects from a class where I learned how to use Unreal. I sadly won't post any of my code here since I don't want future students to be able to cheat. 

## Networked Shooter
For this project, I had to take the 1st person shooter Unreal starter game and make it work in multiplayer. In the process, I learned how to use remote procedure calls to sync the inputs from the players with the server. In the video, you can also see a chat function I added with global and team based messages.

[![Video thumbnail](https://img.youtube.com/vi/qak8a8i-XD4/0.jpg)](https://www.youtube.com/watch?v=qak8a8i-XD4)

## Top Down Puzzle
This was the first thing I ever built using Unreal. I built a puzzle system which lets the player light up switches and open doors when they step on pressure plates. The fire effect can spread to other objects in the scene and also triggers one of the doors to open.
